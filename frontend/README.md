# Registro de Participantes

Aplicación React para registro de participantes con las siguientes características:

- Formulario de inscripción con validación
- Filtros de búsqueda por nombre, modalidad y nivel
- Persistencia de datos en LocalStorage
- Diseño responsivo con Tailwind CSS

## tecnologias

- React 18
- TypeScript
- Vite
- Tailwind CSS

## instalación

```bash
npm install
npm run dev
```

## funciones

- Registro de participantes con validación de términos
- Filtrado por nombre, modalidad (Presencial/Virtual/Híbrido) y nivel (Principiante/Intermedio/Avanzado)
- Eliminación de participantes
- Colores diferenciados por nivel
- Contador de participantes
- Persistencia en LocalStorage
